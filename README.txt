شبكة النائل - حزمة تطبيق ويب قابلة للنشر

الملفات:
- index.html: التطبيق الحالي مع ربط Supabase الموجود في النسخة التي زودني بها المستخدم.
- manifest.webmanifest: تعريف التطبيق القابل للتثبيت.
- sw.js: عامل خدمة لتخزين هيكل الواجهة فقط، مع عدم تخزين طلبات Supabase أو بيانات الدخول.
- icon.svg: أيقونة التطبيق.

النشر:
ارفع محتويات هذا المجلد إلى مشروع Vercel كـ Static Site / Other، واجعل مجلد الجذر هو هذا المجلد ولا توجد خطوة build. يلزم HTTPS حتى يعمل Service Worker والتثبيت.

مهم: لم يتم النشر إلى الإنترنت بعد؛ يتطلب ربط حساب الاستضافة وموافقة مالك الحساب.
