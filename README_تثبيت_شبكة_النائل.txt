حزمة تطبيق شبكة النائل (PWA)

محتويات الحزمة التي يجب أن تكون جميعها في جذر مشروع GitHub نفسه:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

طريقة النشر:
1) ارفع الملفات الأربعة إلى مستودع GitHub بجانب بعضها (في الجذر، وليس داخل مجلد فرعي).
2) استبدل index.html بالنسخة الموجودة في هذه الحزمة.
3) انتظر انتهاء نشر Vercel.
4) افتح رابط الموقع عبر HTTPS.

التثبيت على Android:
- افتح الموقع في Chrome.
- افتح قائمة ⋮ ثم اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- وافق على التثبيت، وستظهر أيقونة شبكة النائل.

التثبيت على الكمبيوتر:
- افتح الموقع في Chrome أو Edge.
- اضغط أيقونة التثبيت التي تظهر بجانب شريط العنوان، أو من القائمة اختر "تثبيت شبكة النائل".

ملاحظة:
- يجب نشر الملفات الأربعة على نفس النطاق حتى يعمل التثبيت.
- الاتصال بالإنترنت مطلوب لمزامنة بيانات Supabase. التخزين المؤقت يساعد على فتح واجهة التطبيق، لكنه لا يعني أن كل عمليات النظام تعمل دون إنترنت.
